# Showcase artwork

Posters, backdrops and episode stills for the showcase library (`../showcase.json`), used for store screenshots and demos on a local dev server.

- AI-generated
- Fictional titles, people and places - no real people, brands, logos or text
- Metadata stripped (no EXIF, XMP, IPTC or content credentials)
- Dev assets only: not part of the app, never bundled into a build
