Rillwood Kids

Draft of a kids mode for phones and tablets (roadmap Ideas). Kids tap fast and scroll fast: one screen, big pictures, a quick search by name, nothing to set. Two ways in: a kids user on Jellyfin, or kids mode on your own account with an age filter. Grown-ups get out through a hold + a quick math question.

Frames are real size - scroll them. Show names and art are fictional stand-ins.

  • No hero, no call to action: the kid picks. Continue Watching is just the first tiles of the feed (progress bar, tap resumes) - same size as the rest, no "Resume" label.
  • Faces on top: every show the kid can see, one row that scrolls sideways, last watched first. White ring = new episode since last open. Tap opens Show (03).
  • Feed: one column, 16:9, full width minus 16 pt. Order: Continue Watching → Next Up → Recently Added → the rest shuffled per day, paged like Library. Episodes and movies mixed; never a whole series tile here (that's a face).
  • Tile: tap plays (episode resumes). Press = shrink to 96 %, no long-press menu. Length pill for unstarted, ✓ for watched, progress bar for started (same rules as the main app).
  • No header title, no tab bar. Left: the brand lockup (mark + "Rillwood" + "kids" tag) - a tap does nothing, a 2 s hold fills a ring around the mark and opens the grown-up gate (05); no lock icon to make kids curious. Right: search (52 pt, opens 02), alone on its side so nothing else sits next to it.
  • Mis-taps: a tap that starts after a scroll fling is a stop, not a play (RN's default on ScrollView, keep it). The second tap within 600 ms on the same tile is ignored.
  • Debounce navigation: one open player / show at a time - fast double taps never stack two screens.

  • Open: the search button on Home (and on Offline / Tablet). The field is focused, keyboard up, nothing to tap first.
  • Before typing: every show as a big face (3 across) - search for kids who can't spell yet. Tap = Show (03).

04Player - the app's player, unchanged

Kids mode only changes how you get to a video. Once it plays, it's the normal player: same controls, tracks menu, Up Next + autoplay, resume, reporting, PiP, offline play (docs/context/player.md). No kids overlay, no screen lock.

  • Close returns to where the kid came from (Home, Search or Show).
  • Up Next plays the next episode of the show, as today; autoplay follows Settings → Playback.
  • Audio + subtitles from the grown-up defaults (Settings → Playback) - the kid can still change them in the tracks menu.

  • Step 1, hold: the mark is the top-left brand lockup ("Rillwood" + a small "kids" tag) - it reads as a logo, not a button. Pressed, it grows a little and a white ring fills around it over 2 s, with a small "Grown-ups: keep holding" tag under it. Letting go drains the ring; the tag stays 3 s after a tap or an early let-go, so it can be read, then fades. A quick tap opens nothing.
  • Step 2, math: a sheet over Home (Cancel, a tap outside or a swipe down closes). One multiplication, both numbers 6-9 (36-81), written in words ("seven times eight") so digits alone don't give it away; type the answer on the pad - no answer choices to guess from. It checks once both digits are in: wrong = a shake and a new question, right = what's behind it.
  • Why no PIN: nothing to set up or forget, and nothing a kid can watch over a shoulder. Trade-off: a kid who knows the times tables gets out - fine for the "don't wander out by accident" goal; Screen Time is the real lock.
  • Behind it, kids account (shown): Downloads - the kids download page (10), without leaving kids mode; Settings - grown-up settings for kids mode (07c); Switch Account - the account list. Shared phone: Downloads, Settings and Leave Kids Mode - back to your normal app. No "full app" on a kids account: everything a grown-up needs there is Downloads + Settings.
  • Store: this also serves as the App Store "parental gate" (Guideline 1.3) if links out ever show up in kids mode - today there are none.
  • Relaunch: kids mode survives app kill and restart - the app opens straight into it until a grown-up leaves (shared phone); a kids account always opens in it.

Got It
  • Shared phone - the row: Kids Mode in Settings, its own group right under the accounts (it's "who's using the phone", like the accounts). Value = the age once set up, else "Set up". Tap → the Kids Mode page (07b) → Start Kids Mode. From Home: avatar → Kids Mode → Start = 3 taps.
  • Kids account - no button at all: switching to Mia (tap her row) is entering kids mode. Her row carries a small Kids tag so it's clear what the tap does.
  • Account page: a Kids account row (On / Off checkmark list, like every setting). How an undetected kids user gets marked, or a mark gets undone.
  • Way in = a short fade to kids Home (no slide - it replaces the whole app, the stack is cleared like an account switch).
  • First time only (per device): a coach mark over kids Home - the Rillwood mark lit up with a pulsing ring, "hold it 2 s, then answer a quick sum", Got It. The way out is hidden on purpose, so the grown-up has to be told once.
  • Not now: an iOS / Android home-screen quick action "Kids Mode" (long-press the app icon) - nice for shared phones, but a new dep (expo-quick-actions, approval). Later.
  • Apple TV: Who's Watching shows a kids account with the same tag; picking it opens kids mode. Shared-phone mode is phone / tablet only.

  • 07a Kids account - marking it: after sign-in (password or Quick Connect), only when detected, one more step: Who's it for? A grown-up / A kid. Detected = the user's server policy has a rating limit; "A kid" pre-picked (/Users/Me → Policy.MaxParentalRating, readable without admin) - with the hint line saying why. Not detected (most sign-ins): no extra step. Any account can be marked on its Account page (06). A kids user limited by libraries only isn't detected - grown-ups have limited libraries too - so it's marked by hand.
  • Kids account - using it: while it's the active account the app is kids mode - at launch and on every switch to it. The server decides what shows up (rating, libraries); the app adds no filter.
  • 07b Shared phone: Settings → Kids Mode on your own account (also a row in the avatar menu). Age: 3+ / 7+ / 10+ / 13+, remembered per account. Libraries (default: all), Unrated videos (default: Hide - home videos and odd files have no rating). Start = kids mode on your account until a grown-up leaves through the gate.
  • Age → ratings: each step maps to a score on the server's own rating table (/Localization/ParentalRatings, per server country), so US, UK, DE ratings all line up. The small line under each step lists the ratings it lets in on this server (draft shows US examples).
  • Shared filter, where (tested on 12.1 + 10.11, docs/context/kids.md): every list is an /Items request with the limit (maxOfficialRating) - faces, search, and Continue / newest too (/UserItems/Resume and /Items/Latest ignore it). Episodes have no rating: one is kept when its show is in the allowed shows - that also filters Next Up (no server filter) and unrated shows. TV-14 stays out at 13+. Offline: a download saves its rating score (an episode: its show's); older ones count as unrated.
  • Say it plainly: the shared filter hides, it doesn't block - anyone through the gate sees everything. The footer says so and points to a kids user on the server.
  • 07c Settings from kids mode: gate → Settings. The grown-up bits that matter while kids mode is on, in the normal Settings look, without leaving it: Kids Mode (age, libraries, unrated - shared phone only), Playback (audio / subtitle language, play next), Downloads (network, storage limit), Display (appearance, subtitle style). Same settings as the full app - one store, not a copy. Back to Kids Mode or ‹ returns.
  • Left out there: accounts (the gate has Switch Account), About, Licences, sign out - full-app things.
  • Downloads - grown-ups only: kids never see a download button; gate → Downloads (10). Needs "Allow downloads" for the user on the server.
  • Shared phone downloads: your own downloads, shown in the kids offline feed only if they pass the age filter.
  • Storage: one setting per account: kids: off | account | { age, libraries, unrated } in src/settings.ts; read on boot to pick the first screen.

  • The switch: the app's connection check (connection.ts) flips kids mode between the server and the downloads store. Home re-fills from downloads when the check says offline, and back when it's online again - no message, only the chip appears / goes.
  • Opened on the plane: straight into kids mode on the last account (kept on the phone, no sign-in). The launch check fails at once in airplane mode (no 8 s wait), Home fills from downloads; posters + stills come from the art saved with each download. Weak Wi-Fi that doesn't answer: loading placeholders until the 8 s check gives up, never a half-filled screen. Landing: back to the full list on the next check (foreground / while offline), flight progress syncs.
  • Offline Home: faces = shows with at least one downloaded episode; feed = downloaded movies + episodes, same order rules. Search finds only downloads.
  • Offline Show: only its downloaded episodes, seasons as dividers if more than one; "Next" = the next one among the downloaded. Not downloaded ones are left out, not greyed.
  • Chip: "✈︎ Downloaded" under the bar, not tappable - tells the grown-up why things are missing.
  • Lost mid-tap: the connection drops right as a not-downloaded tile is tapped → a calm full-screen "☁︎ Needs the internet" with one big Back, then Home re-fills from downloads.
  • Online, downloaded items look the same - no badge for kids. The grown-up checks on the downloads page (10).
  • Nothing downloaded: a big moon + "Nothing to watch offline" and nothing else to press.
  • Shared phone: your downloads, only those that pass the age filter. Auto-remove still runs; the player hold keeps a file that's playing.

  • Way in: hold the Rillwood mark → math → Downloads. Kids mode stays on underneath; Back to Kids Mode (or ‹) returns to kids Home. Kids never see a download button anywhere.
  • The list: the kid's shows (faces) and movies, A-Z, plus a search field on scroll-up. Already kept ones first. Same filter as the kids screens (server on a kids account, the age filter on a shared phone).
  • One button per show: ↓ = keep the next 5 episodes (from Next Up, across seasons). ✓ = kept; tap again → Remove. Ring = downloading. A kid never thinks in seasons, and 5 is a car trip.
  • Tops itself up: a watched episode makes room - auto-remove takes it (watched cooldown setting), the next one downloads on the next sync run (Wi-Fi only by default). So a kept show always has ~5 ready.
  • Movies: ↓ / ✓ like today's download button.
  • Storage line: space used by this account's downloads, free space, the network rule (Settings → Downloads). The storage limit and Wi-Fi rule are the app's, unchanged.
  • Under the hood: the normal downloads store and native module (docs/context/downloads.md) for the active account; new is only the "keep next N of a show" rule. Needs "Allow downloads" for the user on the server.
  • Exact episodes: tap a show's row (not its button) → its episodes by season, each with ↓ - for picking a whole season or one special episode.

-Open questions

  • Apple TV: same idea, but focus + remote change it (faces as the top shelf, hold Menu for the gate). Separate draft once the phone version is agreed.
  • Look: draft keeps the app's dark palette + white accent with brighter art. Alternative: a light, softer kids palette - decide before building.
  • Limits (episodes, bedtime, daily time): left out - iOS Screen Time / Android Digital Wellbeing cover it.
  • Feed order "shuffled per day": or strictly newest? Shuffle keeps old favourites in view; strict order is more predictable for grown-ups.
  • Code shape: own route group (kids)/ with home, show/[id]; the player stays as is. Lists are filtered /Items requests (above) plus Next Up.
