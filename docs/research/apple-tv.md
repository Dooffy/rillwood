# Apple TV (tvOS) - spike notes

Date: 2026-11-05. Throwaway spike: the current app (`main` @ `5b530a7`) built for the Apple TV 4K simulator (tvOS 27.2, Xcode 27.2, Expo SDK 58, RN 0.88.1). All hacks reverted; this file keeps what we learned. Plan: `docs/roadmap.md` (TV). Screen drafts: [`apple-tv-screens.html`](apple-tv-screens.html) (open in a browser). Tags: **[V]** seen in the spike, **[U]** unverified / judgement.

## Native modules on tvOS

`pod install` skips modules that don't declare tvOS ("supports iOS but target is tvOS"). Their JS then crashes at import (`requireNativeModule`) unless gated.

| Module                                                                                                       | tvOS    | Note                                                                                                                          | Tag       |
| ------------------------------------------------------------------------------------------------------------ | ------- | ----------------------------------------------------------------------------------------------------------------------------- | --------- |
| `modules/mpv` + MPVKit fork                                                                                  | Yes     | Podspec `:tvos => '15.1'`; MPVKit podspec `s.tvos.deployment_target = '14.0'` (fork notes audiounit as the tvOS audio output) | [V]       |
| `modules/downloads`                                                                                          | Skipped | No downloads on TV anyway - gate the JS                                                                                       | [V]       |
| `expo-screen-orientation`                                                                                    | Skipped | No orientation on TV - gate `src/orientation.ts` + player                                                                     | [V]       |
| `expo-router` (native part)                                                                                  | Skipped | JS routing + native stack / tabs still work; check what the native part adds (toolbar, link preview)                          | [V] / [U] |
| `@expo/dom-webview`                                                                                          | Skipped | Unused                                                                                                                        | [V]       |
| `expo-secure-store`, `expo-sqlite`, `expo-image`, `expo-crypto`, screens, reanimated, gesture-handler, glass | Linked  | Worked in the spike (glass not seen on screen)                                                                                | [V]       |

## Problems hit and the real fix

| #   | Problem                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | Spike hack                                                                                                                                                               | Real fix                                                                                                                                                                                                                                         | Tag |
| --- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --- |
| 1   | **Swift compiler crash** (Swift 6.4.2) in `expo-modules-core` `AsyncFunctionDefinition.swift` (`case .failure(let error as any Error)` in a `switch consume`). iOS never compiles it - SDK 58 ships Expo modules precompiled; tvOS gets no xcframeworks and builds from source                                                                                                                                                                                                                                  | Edited `node_modules` to `case .failure(let error)`                                                                                                                      | `patch-package` (or upstream fix); re-check on every Xcode / SDK bump                                                                                                                                                                            | [V] |
| 2   | x86_64 simulator slice failed in the same module (likely the same crash)                                                                                                                                                                                                                                                                                                                                                                                                                                        | Built arm64 only                                                                                                                                                         | Same fix as 1; Apple Silicon only is fine for dev                                                                                                                                                                                                | [U] |
| 3   | **Keychain `-34018`** ("neither application-identifier nor keychain-access-groups") on sign-in - token save failed, UI said "Something went wrong"                                                                                                                                                                                                                                                                                                                                                              | Build with `CODE_SIGN_IDENTITY=-` (Sign to Run Locally)                                                                                                                  | Normal signed builds carry the entitlement. Don't build with `CODE_SIGNING_ALLOWED=NO`; hand re-signing with `codesign --entitlements` fails at launch (`OS_REASON_EXEC` - simulator entitlements live in the binary's `__entitlements` section) | [V] |
| 4   | **No visible focus**: `Pressable` gets focus but draws nothing                                                                                                                                                                                                                                                                                                                                                                                                                                                  | Global `Pressable` wrapper: scale 1.08 + white outline when `focused` (tvOS `Pressable` passes `focused` to its style function)                                          | Focus styles in our own components (cards, buttons, rows) per the screen drafts                                                                                                                                                                  | [V] |
| 5   | **Crash on Play**: gesture-handler attaches a pinch recognizer, which tvOS doesn't have - UIKit aborts (`-[UIView _addGestureRecognizer:atEnd:]` → `arrayByAddingObject:` nil)                                                                                                                                                                                                                                                                                                                                  | Player gestures off on TV                                                                                                                                                | TV player without touch gestures (no pinch / double-tap / pull-down)                                                                                                                                                                             | [V] |
| 6   | **Remote presses don't reach the player**: it's a `transparentModal`; remote events are caught on the root view, a native modal lives outside it. Only Menu (system Back) worked                                                                                                                                                                                                                                                                                                                                | Player `presentation: 'card'` on TV                                                                                                                                      | Same on TV; check every other modal / form sheet (ActionSheet, option pages)                                                                                                                                                                     | [V] |
| 7   | Player had no remote mapping                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | `useTVEventHandler`: select = show controls, playPause = toggle, left / right (controls hidden) = ±10 s, up / down = show controls; ignore key-down (`eventKeyAction` 0) | Full mapping incl. swipe-to-scrub on the touch surface, Menu = hide controls then close                                                                                                                                                          | [V] |
| 8   | JS `console.log` doesn't show in the system log for Release builds                                                                                                                                                                                                                                                                                                                                                                                                                                              | -                                                                                                                                                                        | Debug with a Debug build + Metro                                                                                                                                                                                                                 | [V] |
| 9   | **Keyboard screen copies the field**: tvOS shows the `TextInput` in its full-screen keyboard with the field's own font, colour and padding - any text style (even only `color`) gives React Native's default text attributes (14 pt), so the typed text is tiny / off centre; a colour dropped mid-edit turns later letters black. react-native-tvos #1134 (in 0.88) strips attributes from the value only, not `defaultTextAttributes`. A field with no style is right in the keyboard but 14 pt on the screen | Tried colours, sizes, a light system capsule; then a plain test field next to ours (keyboard right, screen wrong)                                                        | `TvTextField`: a capsule we draw (our font / colours) opens the keyboard through a hidden `TextInput` with no style (`autoFocus` on a fresh mount - the one way to start editing from code on tvOS)                                              | [V] |
| 10  | **ActionSheet (RN `Modal`) doesn't take the remote**, same as 6                                                                                                                                                                                                                                                                                                                                                                                                                                                 | -                                                                                                                                                                        | `TvMenu` in the app's own view (`TvMenuHost`), focus trapped, Menu key taken while open (`TVEventControl.enableTVMenuKey` + `BackHandler`)                                                                                                       | [V] |

## Platform facts to design for

| Fact                                                                                                                     | Impact                                                                                                                                                                            | Tag                         |
| ------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------- |
| tvOS gives apps no lasting local storage: caches can be purged, `UserDefaults` is small (~500 KB); the Keychain persists | Accounts list + settings can't rely on the kv-store (SQLite file) - move to UserDefaults / Keychain on TV. Tokens already in the Keychain. No downloads, offline queue or offload | [U] Apple docs, not re-read |
| No browser                                                                                                               | About links (source, privacy) as QR codes                                                                                                                                         | [U]                         |
| Remote only, no touch                                                                                                    | Every action reachable by focus; no gestures; long-press for item menus                                                                                                           | [V]                         |
| Same bundle id possible                                                                                                  | Add tvOS to the existing App Store record (Universal Purchase)                                                                                                                    | [U]                         |
| Store assets                                                                                                             | Layered app icon (2-5 layers; 400 × 240 and 1280 × 768), Top Shelf 1920 × 720 + 2320 × 720, screenshots 1920 × 1080 or 3840 × 2160                                                | [U]                         |
